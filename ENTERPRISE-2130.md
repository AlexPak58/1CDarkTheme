# Предприятие 8.3.27.2130 x64: толстый/тонкий клиент Такси

Отдельная палитра Предприятия сохранена при обновлении на b412b20 / v11.
Ярлык «Тёмная тема 1С — Предприятие» открывает вкладку сеансов и панель
ручного запуска с выбранным тонким клиентом. Укажите сервер\база или
полный каталог файловой базы, выберите клиент и нажмите кнопку запуска.
Палитра берётся из общих настроек или исключения режима Enterprise.
Настройки и пресеты общие: %LOCALAPPDATA%\1CDarkTheme.

Предприятие окрашивается только при явном запуске из панели. Уже открытые
клиенты автоматически не изменяются. Палитра фиксируется до закрытия
запущенного сеанса. Пауза/выход агента возвращает цвета только Конфигуратора.
Для штатных цветов Предприятия запустите новый сеанс обычным способом
либо с выключенной темой/пресетом native.json.

Профиль остаётся предварительным. Отдельная DLL и точные хеши EXE/grphcs;
нейтральные векторные цвета конфигурации могут измениться, HTML и картинки
сохраняют оформление. Все бизнес-формы, отчёты и условное оформление
не проверены. Новые зоны рамок/поиска/прокрутки upstream предназначены
для Конфигуратора, не являются универсальной перекраской бизнес-форм.
