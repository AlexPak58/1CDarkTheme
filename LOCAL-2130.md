### Штатная палитра редактора модулей

«Серый сланец» для BSL хранится в `presets/module-editor/slate-gray.json`.
Конфигуратор читает эти 15 цветов из штатного раздела
`ModuleColorCategory` файла `%APPDATA%\1C\1cv8\1cv8.pfl`.
Палитра общая для Конфигураторов пользователя Windows. Цвета видны в
«Сервис → Параметры → Модули → Редактирование». Подсветка текущего
идентификатора синяя, совпадений выделенного идентификатора — сливовая.
Переключатель темы окна управляет оформлением интерфейса. Палитра BSL
действует независимо через штатные параметры редактора.

Для предварительной проверки запустите из каталога проекта
`py -3 tools/designer-editor-preset.py --preset presets/module-editor/slate-gray.json`.
Для сохранения добавьте `--apply` при закрытых Конфигураторах.
Команда выводит путь к резервной копии. При необходимости
`py -3 tools/designer-editor-preset.py --restore-from <копия.pfl> --apply`
восстанавливает только раздел цветов.
